# ShopSphere E-Commerce Analytics Platform

## Business Problem

ShopSphere has large amounts of customer, order, product,
payment, review, and geographic data but lacks a centralized
analytics platform for business decision-making.

## Objective

Build an end-to-end analytics platform that integrates,
cleans, transforms, models, analyzes, and visualizes
e-commerce data.

## Business Questions

### Revenue
- What is total revenue?
- How is revenue changing over time?
- Which countries generate the most revenue?
- Which categories generate the most revenue?

### Products
- What are the top-selling products?
- Which products are declining?
- Which categories perform best?

### Customers
- How many customers do we have?
- How many are new vs returning?
- Who are the highest-value customers?

### Orders
- How many orders are placed?
- What is average order value?
- What is the cancellation rate?

### Geography
- Which countries perform best?
- Which cities generate the most revenue?
- Where are customers concentrated?

## Expected Deliverables

- Python ETL pipeline
- PostgreSQL database
- SQL transformation layer
- Data warehouse model
- KPI framework
- Power BI dashboard
- Data dictionary
- Technical documentation
- Business insights
